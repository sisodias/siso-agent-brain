Best principles

A shared brain is a state boundary, not a gravity well

Consumers naturally accumulate beside a useful database. Keep the repository coherent by owning storage, API, schema evolution, and conservative portability while routing learning, scheduling, model infrastructure, workspace control, and source discovery to independent Works.

Offline durability must preserve semantics

Queue only writes that can safely replay. Keep the exact API path and structured body, make replay explicit, retain failures, and verify a real offline-to-online round trip.

Uninstall code, preserve state

Package code, database files, authorization tokens, and outboxes have different lifecycles. Removal of one must never imply removal of the others.
