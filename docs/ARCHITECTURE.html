Security posture

  • Read, write, and spawn tokens are separate files or an explicit environment token.
  • The default bind is loopback and the data-rendering face is off.
  • The public health endpoint excludes database paths and coordination records.
  • Database, tokens, outbox, logs, and runtime state are Git-ignored and never part of a release.
  • Uninstall removes code only; state survives package upgrades and removal.

Evolution

Work identity is stable; this layout is not sacred. New consumers should first use the API. A subsystem earns its own repository when it creates an independent outcome and can release without forcing an Agent Brain release.
